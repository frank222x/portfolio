# Portfolio — Francis Langlois

Site statique en français, prêt pour GitHub Pages.

## Fichiers
- `index.html` : contenu du portfolio.
- `style.css` : style responsive sombre.
- `README.md` : instructions de publication.

## Publication gratuite avec GitHub Pages
1. Connectez-vous à GitHub.
2. Créez un nouveau dépôt **public** nommé `portfolio-cybersecurite` (ou un autre nom).
3. Téléversez `index.html`, `style.css` et `README.md` à la racine du dépôt.
4. Dans le dépôt, ouvrez **Settings → Pages**.
5. Sous **Build and deployment**, choisissez **Deploy from a branch**.
6. Sélectionnez la branche `main` et le dossier `/(root)`, puis cliquez **Save**.
7. Attendez le déploiement. L’adresse sera généralement `https://VOTRE-NOM-GITHUB.github.io/portfolio-cybersecurite/`.

Documentation officielle : https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Avant de publier
- Vérifiez les renseignements de formation, d'emploi et de projets.
- Ajoutez une adresse courriel professionnelle si vous souhaitez être contacté.
- Ne publiez jamais de clés VPN, mots de passe, jetons, adresses IP publiques, adresses privées réelles ou journaux non expurgés.
- Les noms de domaine et adresses réseau de l'infrastructure réelle ont été omis.
- Vérifiez les liens et coordonnées.

## Domaine personnalisé (facultatif)
Configurez d'abord le domaine dans GitHub (**Settings → Pages → Custom domain**), puis les enregistrements DNS chez votre registraire. Documentation : https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
